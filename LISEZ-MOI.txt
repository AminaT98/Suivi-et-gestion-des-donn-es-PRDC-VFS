PRDC-VFS — TABLEAU DE BORD AVEC CARTE GPS

CONTENU DU DOSSIER
- PRDC_VFS_Tableau_de_bord.html : page du tableau de bord
- styles.css : styles de l'interface
- app.js : chargement des fichiers Excel, filtres, points GPS et fiches
- Infrastructures.xlsx
- Interconnexion_transfrontalière.xlsx
- Activités_de_cohésion_sociale.xlsx
- Ouvrir_PRDC_VFS.bat : ouvre le tableau de bord via un serveur local Python
- Les trois logos doivent rester dans ce dossier : logo-projet.png, logo-banque.png, logo-rim.png

UTILISATION
1. Extraire tous les fichiers dans un seul dossier.
2. Garder les logos dans ce dossier.
3. Double-cliquer sur Ouvrir_PRDC_VFS.bat.
4. Le tableau de bord charge automatiquement les trois fichiers Excel depuis ce dossier.
5. Chaque enregistrement ayant une latitude et une longitude valides apparaît sur la carte. Les points proches peuvent être regroupés en cercles numérotés ; cliquer sur le groupe zoome, puis cliquer sur un point ouvre la fiche du projet.
6. Pour actualiser les données, remplacer les fichiers Excel en gardant exactement les mêmes noms, puis recharger la page du navigateur.

IMPORTANT
Le chargement automatique de fichiers Excel locaux n'est pas autorisé par les navigateurs quand on ouvre le HTML directement (file://). Le lanceur démarre un petit serveur local avec Python. Une connexion Internet est nécessaire pour les bibliothèques JavaScript et le fond de carte.
